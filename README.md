# Sourav Ranjan Pradhan — Portfolio

A premium, dark-glassmorphic personal portfolio website built with pure HTML, CSS & JS.

## 🚀 Quick Start

1. Clone/download this repo
2. Open `index.html` in your browser — that's it!

## 📦 Deploy to GitHub Pages (Free)

1. Create a new repo on GitHub (e.g., `portfolio` or `yourusername.github.io`)
2. Push all files to the `main` branch
3. Go to **Settings → Pages → Source → Deploy from branch → main**
4. Your site will be live at `https://yourusername.github.io/portfolio/`

## 📦 Deploy to Netlify (Free)

1. Go to [netlify.com](https://netlify.com) and sign in with GitHub
2. Click **"Add new site" → "Import an existing project"**
3. Select your repo → Deploy. Done!

## 📦 Deploy to Vercel (Free)

1. Go to [vercel.com](https://vercel.com) and sign in
2. Click **"New Project"** → Import your GitHub repo
3. It auto-detects static sites. Click **Deploy**.

## 🌐 Custom Domain

1. Buy a domain (e.g., from Namecheap, GoDaddy, Cloudflare)
2. Update the `CNAME` file with your domain
3. Add DNS records as instructed by your hosting provider

## 🛠️ Customization

- **Colors**: Edit CSS variables in `css/style.css` under `:root`
- **Content**: Edit `index.html` directly
- **Contact Form**: Replace the demo handler in `js/main.js` with [Formspree](https://formspree.io) or [Web3Forms](https://web3forms.com)
- **Profile Photo**: Replace the `hero-avatar-placeholder` div with an `<img>` tag
